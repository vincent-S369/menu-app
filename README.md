# 我的每周菜单

这是一个给家庭自用的本地每周菜单 app，用来记录菜谱、安排每周菜单，并根据菜单自动生成采购清单。

第一版重点是简单、稳定、无月费：不需要登录、不需要后端、不需要数据库，数据直接保存在当前浏览器的本地存储中。

## 技术结构

- `index.html`：页面结构，包含应用的基础 HTML 和 CSS/JS 文件引用。
- `style.css`：页面样式，负责布局、按钮、表单、菜谱卡片、菜单卡片和采购清单外观。
- `app.js`：业务逻辑，负责菜谱管理、每周菜单管理、采购清单生成、数据备份、页面切换和本地保存。
- `localStorage`：浏览器本地数据保存，用于保存菜谱、每周菜单和采购清单勾选状态。

## 已实现功能

- 菜谱新增、编辑、删除
- 每周菜单新增、编辑、删除
- 每周菜单按星期和餐次排序
- 同一天同一餐不能重复安排
- 删除菜谱时同步清理相关菜单
- 编辑菜谱名时同步更新菜单中的菜名
- 采购清单根据每周菜单自动生成
- 重复食材自动合并
- 采购清单支持已购买勾选
- 刷新页面后数据保留
- 支持导出 JSON 数据备份
- 支持从 JSON 文件导入数据
- 导入数据前会弹窗确认，避免误覆盖当前数据
- 导入错误格式文件时会提示“文件格式不正确”

## 当前不做的功能

- 不做登录
- 不做云同步
- 不做图片上传
- 不做数据库
- 不做后端
- 不做 App Store 发布

## 如何运行

直接用浏览器打开 `index.html` 即可使用。

如果浏览器对本地文件的 `localStorage` 支持不稳定，可以在项目目录运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```

## 每次修改后的验收清单

每次修改代码后，建议按下面清单验收：

- 打开页面后，五个入口都可以正常切换：菜谱库、每周菜单、采购清单、新增菜谱、数据备份。
- 新增菜谱后，菜谱可以出现在菜谱库中。
- 菜谱可以编辑，编辑后内容正确更新。
- 菜谱可以删除，删除后不再显示。
- 新增每周菜单后，菜单可以正常显示。
- 每周菜单可以编辑，编辑后星期、餐次和菜谱正确更新。
- 每周菜单可以删除，删除后不再显示。
- 每周菜单按星期和餐次排序。
- 同一天同一餐重复添加时，会提示不能重复安排。
- 删除某个菜谱后，使用该菜谱的每周菜单会被同步清理。
- 编辑某个菜谱名称后，使用该菜谱的每周菜单会同步更新菜名。
- 采购清单可以根据每周菜单自动生成。
- 多个菜单中重复出现的食材会合并计数。
- 采购清单的已购买勾选状态可以切换。
- 数据备份可以导出 JSON 文件，文件中包含 `recipes`、`weeklyMenus` 和 `checkedItems`。
- 数据备份可以从 JSON 文件导入，导入前会弹窗确认“导入会覆盖当前本地数据，确定继续吗？”。
- 导入成功后会提示“导入成功”，当前页面状态会更新。
- 导入错误格式文件时会提示“文件格式不正确”，页面不应崩溃。
- 刷新浏览器后，菜谱、每周菜单和采购清单勾选状态仍然保留。
- 浏览器控制台没有明显报错。

## 后续建议

- 给菜谱增加内部 `id`，避免未来出现同名菜谱时影响菜单关联。
- 支持更多食材分隔方式，例如逗号、换行。
- 增加一键清空采购清单勾选状态。
- 增加更细的导入校验和错误提示，例如提示缺少哪个字段。
